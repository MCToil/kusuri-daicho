# 薬台帳

**https://mctoil.github.io/kusuri-daicho/**

定期薬の**仕入れ（処方・購入）を記録して、いつ切れるかを先に知る**ためのアプリです。
飲み忘れを見張るのではなく、**薬が足りているかどうか**だけを扱います。

依存ライブラリなし。`index.html` 1枚だけで動きます。

## 使う

上のアドレスを開くだけです。iPhone では Safari で開いて「ホーム画面に追加」しておくと、アプリのように使えます。

ローカルで動かす場合は `index.html` をブラウザにドラッグするか、次を実行します。

```bash
python3 serve.py
```

→ http://localhost:3800

データはこの端末のブラウザ（localStorage）に保存されます。同期を設定しない限り、外部には送信されません。
オリジンごとに保存先が分かれるので、公開アドレスとローカルは別のデータになります。複数の端末で同じ台帳を使うには、下の**同期**を設定してください。

## 画面

| タブ | 内容 |
| --- | --- |
| 一覧 | 残り日数の少ない順に薬カード。要補充・切れているの件数、今月／今年の薬代、入手先ごとの受診目安 |
| 記録 | 仕入れを1件ずつ入力。新しい薬・入手先・タグはここからその場で登録できる |
| 薬 | 薬の登録・編集。1日の消費量、いつもの入手先、補充アラート日数 |
| 履歴 | 仕入れ記録の一覧。年・薬・タグでしぼり込み、その場で編集 |
| 集計 | 年間の薬代と、月別・薬別・入手先別・タグ別・年推移 |
| 設定 | 同期、入手先とタグの管理、補充アラートの既定値、JSON/CSV 書き出し・復元、全消去 |

右上の <kbd>⟳</kbd> はどのタブからでも押せます。未同期の変更があるときは色が変わります。

## 残量の考えかた

このアプリの中心は、**仕入れ日と数量から「いつ切れるか」を出す**ことです。

```
その仕入れが供給する日数 = 数量 ÷ 1日の消費量   （日数分を直接入れた場合はそちら）
消費が始まる日           = max(前の供給が尽きた日, 仕入れ日)
```

つまり、前の薬が残っているうちに次をもらった分は**捨てずに後ろへ積み上がります**。
逆に、切らした期間があると鎖が切れて、その仕入れ日から数え直します。

例：1日1錠の薬

| 仕入れ日 | 数量 | 消費開始 | 尽きる日 |
| --- | --- | --- | --- |
| 5/15 | 56錠 | 5/15 | 7/10 |
| 7/6（4日早く受診） | 56錠 | 7/10 | 9/4 |

残り日数が**補充アラート日数**（既定14日、薬ごとに変更可）を切ると、一覧の上に警告が出ます。
カードの左端の色も、足りている（緑）・そろそろ補充（黄）・切れている（赤）で変わります。

### 棚卸

実際に数えたら計算とずれていた、というときは、種別を**棚卸**にして**いまの残量**を入れます。
その日を起点に数え直され、それ以前の計算は破棄されます。金額と日数は入りません。

### 頓服

1日の消費量を **0** にすると、切れる日を予測せず、数量の積み上げだけを表示します。
頭痛薬や胃薬など、必要なときだけ飲む薬に使ってください。

## 入手先

入手先は登録して使います。記録画面ではプルダウンから選ぶだけで、毎回打ち込む必要はありません。
はじめて行く病院や薬局は、プルダウンの **「＋ 新しい入手先」** を選んでその場で名前を入れれば、保存と同時に登録されます。
設定タブの「入手先」で、名前の変更と削除ができます。**名前を変えると、その入手先を使っている記録もまとめて変わります。**

薬の「いつもの入手先」が空のまま仕入れを記録すると、そのときの入手先が既定として覚えられます。

一覧の「入手先ごとの目安」は、**同じ病院・薬局の薬をまとめて**、そのうちいちばん早く切れる薬の日付を出します。
「みどり内科は9/4までに行けば2種類とも間に合う」という判断のための表です。

## タグ

仕入れ1件ごとに、好きなタグを**いくつでも**付けられます。「保険」「自費」「ジェネリック」など、
自分の分け方を登録して、記録画面でチップを押して選ぶだけです。新しいタグは記録画面の「＋ 新しいタグ」からも足せます。

集計タブに「タグ別」が出ます。1件に複数のタグを付けていると、その額はどのタグにも数えるので、
合計が年間の薬代を超えることがあります。タグの付いていない記録は「（タグなし）」にまとまります。

履歴タブではタグでしぼり込めます。設定タブの「タグ」で名前の変更と削除ができ、名前の変更は記録にも反映されます。

## 薬代の集計

集計タブは**支払額の合計**です。処方・購入いずれも、実際に払った額を入れてください（棚卸は0円あつかい）。
年間合計は医療費控除の材料になりますが、控除の対象は薬代だけではありません。通院の交通費や医科・歯科の窓口負担を足したうえで申告してください。

## Mac mini・MacBook・iPhone で同期する

台帳を自分の**非公開 Gist** に置き、どの端末からも同じものを読み書きします（`keihi-daicho` と同じ仕組みです）。
サーバーもアカウント登録も要りません。必要なのは GitHub のトークン1つです。

### 用意

1. GitHub → Settings → Developer settings → Personal access tokens → **Tokens (classic)** で新規発行
2. スコープは **`gist` だけ**にチェック（ほかは付けないでください）
3. 設定タブ →「同期の設定」にトークンを貼って「保存して同期」。1台目でここに Gist が作られます
4. 「Gist ID をコピー」で ID を控え、2台目以降では**同じトークンと Gist ID** を貼り付けます

トークンはその端末のブラウザにのみ保存され、GitHub 以外には送信しません。書き出す JSON にも Gist にも入りません。
共用の端末では使わないでください。不要になったら「この端末の同期を解除」で消し、GitHub 側でも失効させてください。

### 3台とも同じ台帳にする

Mac mini・MacBook・iPhone のいずれも、**https://mctoil.github.io/kusuri-daicho/** を開いて同じトークンと Gist ID を入れてください。
iPhone は Safari で開いて「ホーム画面に追加」しておくと、アプリのように使えます。

ローカルの `file://` で開いた場合は、公開アドレスとはブラウザの保存領域が別になります。ただし同期先の Gist は共通なので、
そちらにも同じトークンと Gist ID を入れておけば、同じ台帳として扱えます。

### いつ同期されるか

- 何か保存してから約2.5秒後（まとめて1回）
- ほかのアプリから戻ってきたとき（前回から10秒以上あいていれば）
- 右上の <kbd>⟳</kbd> または「今すぐ同期」を押したとき

### ぶつかったとき

両方の端末で編集していた場合など、内容が食い違うときは**黙って上書きしません**。
どちらを残すか、更新時刻と件数を見せたうえで選んでもらいます。次の3つは特に危ないので必ず確認が入ります。

| 状況 | 出るもの |
| --- | --- |
| この端末が空でクラウドに中身がある（新しい端末・全消去のあと） | 既定は「クラウドを取り込む」 |
| 取り込むと手元の記録が減る（別の端末で消えた可能性） | どちらを残すか選ぶ |
| 前回の同期のあと、両方で変更された | どちらを残すか選ぶ |

クラウドを取り込むと手元の内容は入れ替わりますが、**直前の状態が1世代だけ退避**されます。
取り違えたときは同期の設定にある「取り込み前のデータに戻す」で戻せます。

表示テーマだけは端末ごとの好みなので、同期の対象外です。

## データの持ち出し

設定タブから JSON と CSV を書き出せます。JSON は薬・仕入れ記録・設定をすべて含み、そのまま復元できます（同期のトークンは含みません）。
CSV は仕入れ記録を1行ずつ、薬名・種別・数量・日数分・金額・入手先・タグの列で出します（タグは「・」でつなぎます。Excel 用に BOM 付き）。
