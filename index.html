台帳データをご自身の非公開 Gist に置き、どの端末からも同じものを読み書きします。 新しいサービスの登録は要りません。GitHub のトークンを1回発行し、端末ごとに下の欄へ貼り付けてください。

  1. GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic) で新規発行
  2. スコープは gist だけにチェック（ほかは不要です）
  3. 発行されたトークンを下に貼って「保存して同期」。1台目はここで Gist が作られます
  4. 2台目以降は、同じトークンと Gist ID を貼り付けます
トークンはこの端末のブラウザにのみ保存され、GitHub 以外には送信されません。書き出す JSON にも Gist にも含めません。 共用の端末では使わないでください。不要になったら「この端末の同期を解除」で消し、GitHub 側でも失効させてください。
補充アラート
薬ごとに別の日数を設定したい場合は、薬タブの「補充アラート」に入れてください。そちらが優先されます。
データ
データはこの端末のブラウザ（localStorage）にだけ保存されます。外部には一切送信しません。 端末を移すときや、公開アドレスとローカルで同じ台帳を使いたいときは JSON で持ち運んでください。
全消去
薬・仕入れ記録・設定をすべて消します。取り消せません。先に JSON を書き出しておいてください。
